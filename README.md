# IpRiskLight

常驻 macOS 状态栏的 IP 风险监测小工具:定时调用 [ipdata.co](https://ipdata.co)(免费额度 1500 次/天)检测当前出口 IP,在状态栏盾牌图标右下角用红/黄/绿圆点提示风险,点击图标查看详情。

## 使用

1. 构建并运行:

   ```sh
   ./build.sh
   open dist/IpRiskLight.app
   ```

2. 前往 https://ipdata.co 注册免费账号,获取 API key。
3. 点击状态栏盾牌图标,在弹窗中粘贴 API key,保存后自动开始检测。

## 圆点颜色含义

| 颜色 | 含义 |
|---|---|
| 🟢 绿 | 未命中任何风险标志 |
| 🟡 黄 | 代理 / 匿名网络 / 数据中心 IP,或 VPN/代理分数 ≥ 60 |
| 🔴 红 | 威胁 IP / 已知攻击源 / 滥用源 / Tor / Bogon,或威胁分数 ≥ 70 |
| ⚪ 灰 | 未配置 key、请求失败或额度用尽(保留上次详情) |

## 功能

- 状态栏圆点每 3 秒闪烁一次(短暂变暗后恢复),提示监测处于活动状态
- 默认每 10 分钟检测一次,可在设置中改为 5/10/30/60 分钟(10 分钟 ≈ 144 次/天,远低于免费额度)
- 切换 Wi-Fi / 开关 VPN 等网络变化时,几秒内自动触发一次检测
- 弹窗展示:IP、位置(国旗/城市/国家)、ISP、威胁/VPN/代理/信任四项分数、命中的威胁标志
- 当日额度用尽(HTTP 429)自动熔断,次日恢复;手动刷新不受限
- 系统通知:IP 发生变化时提醒(附新位置与风险等级);IP 进入高风险(红色)时提醒一次,持续红色不重复打扰(首次启动会请求通知权限)
- 支持开机自启(设置中开启)

## 开发

```sh
swift build        # 编译
swift test         # 单元测试(风险映射 + 响应解码)
swift run          # 直接运行(无 bundle,功能相同)
```
